Supprimer mon compte FootProba

Dans l'application : Profil → Supprimer mon compte. Sans l'application, utilise ce formulaire avec ton numéro et ton mot de passe.

Effacé définitivement :

  • numéro de téléphone, nom, mot de passe ;
  • solde fictif, paris, montantes, notifications, téléphones enregistrés ;
  • historique Premium.

Conservé sans ton nom ni ton numéro (obligation comptable) : les paiements Premium (montant, date, référence du prestataire). Un paiement en cours est annulé.
