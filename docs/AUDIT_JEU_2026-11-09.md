   mi-temps. **À vérifier** : ces marchés sont-ils passés par la règle des 3 points ? Sinon,
   les retirer du Coupon intelligent et des suggestions de montante pour les sélections.
2. **Écart fort avec le bookmaker sur certains matchs de sélections** : Türkiye – Belgique,
   moteur 10 % / 16 % / 74 %, cotes 3,78 / 4,00 / 1,93 (≈ 26 % / 25 % / 52 % sans la marge).

   suggestion ne convient, l'écran devrait le dire (« Rien de bon pour ce palier
   aujourd'hui : attends la reprise des championnats ») plutôt que proposer
