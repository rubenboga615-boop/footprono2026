## Conclusion

- **La source n'est pas 1xBet** : aucune cote identique. Les cotes de la source sont des
  cotes fractionnaires converties (1,909 = 10/11, 4,333 = 10/3, 1,727 = 8/11, 1,363 = 4/11),
  ce que 1xBet n'affiche pas (2,056, 3,096, 6,31). La réponse ne nomme pas le bookmaker.
- **Écart avec 1xBet** : 0 à 2 % sur les cotes basses (domicile, nul), jusqu'à 5 % sur les
  grosses cotes (Burundi 6,00 contre 6,31). Les cotes de 1xBet bougent elles-mêmes d'environ
  3 % d'une minute à l'autre.
- **Décision** : coupon en direct publié avec des cotes **« indicatives »** (D11), pas
  « 1xBet ». L'écran le dit déjà : « Cotes indicatives : relevées chez un autre bookmaker ».
